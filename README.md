# حروف التوصيل — منصة مسابقات صفّية

موقع ثابت على GitHub Pages يعمل مع Firebase (Auth + Realtime Database).

- `index.html` — المنصة (المدير / شاشة العرض / المتسابق / وضع المعلم).
- `admin.html` — لوحة إدارة المنصة: المشتركون، استيراد بنوك الأسئلة.
- `database.rules.json` — قواعد أمان قاعدة البيانات (منشورة في مشروع Firebase `huroof-6fdad`).
- `test/` — اختبارات واجهة بمحاكي Firebase محلي: `node test/ui.js` و `node test/admin.js`.

## نموذج الاشتراك
- تسجيل مدير جديد = حساب جديد يبقى بانتظار التفعيل.
- بعد تأكيد السداد يضيف المدير المدة (أيام) من لوحة التحكم `admin.html`؛ تُسجَّل كل عملية في `subs/{uid}`.
- المتسابقون وشاشة العرض لا يحتاجون حسابًا؛ يكفي رمز المسابقة (6 أرقام).
